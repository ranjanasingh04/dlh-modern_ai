LLM: Masked Language Modeling and Translation
This project explores pretrained language models with Hugging Face Transformers and PyTorch. It builds a step-by-step masked language modeling (MLM) workflow with RoBERTa, then introduces encoder-only fill-mask inference and encoder-decoder translation.
Learning objectives
- Load a pretrained RoBERTa model for inference.
- Convert text into model-ready token tensors.
- Locate masked tokens and extract their prediction logits.
- Decode predicted token IDs into readable text.
- Use an encoder-only model to fill a mask.
- Use an encoder-decoder model for translation.
